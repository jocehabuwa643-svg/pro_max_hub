# Архив: Pro Max Hub — ULTRA

Апгрейд лендинга по Technical Specification v2.0. Статический сайт без
сборки: открывается как есть, деплоится на GitHub Pages / Netlify копированием папки.

```bash
node devserver.cjs
```
→ http://localhost:4173

ES-модули требуют http(s), поэтому открытие `index.html` через `file://` не работает.

## Что сделано

### Соблюдённые ограничения
- **LOCK-1** — все 12 исходных `href` на месте, ни один не изменён (проверено в браузере).
- **LOCK-2** — все 10 секций и весь текст сохранены. Числа анимируются count-up и восстанавливаются в исходное написание символ-в-символ («1 500 – 5 000 ₽ / день», «Split profit 80/20», «$2 000+»).
- **LOCK-3** — палитра не менялась. Градиенты кнопок углублены **внутри своих оттенков** — это было обязательно: белый текст на `#f59e0b` давал контраст 2.4:1 (провал WCAG). Сейчас все кнопки ≥ 5.1:1.
- **LOCK-4** — года в футере нет. Вместо него роль автора, латинский вордмарк и tagline.
- **LOCK-5** — Higgsfield: потрачено **4.9 из 10 кредитов**, остаток 5.1. Разбор трат, цен и промптов — в `tools/hf-generate.md`.

### Главная находка — кириллицы не было
`Syne` содержит только `latin` + `latin-ext`, `Space Grotesk` — `latin` + `latin-ext` + `vietnamese`.
**Кириллицы нет ни в одном.** В исходном сайте все русские заголовки
(«Работа из дома», «Проп-трейдинг», «Нейросети для заработка», …) и все
чипы/пилюли молча падали в системный `sans-serif` — кинематографической
типографики фактически не было на ~90% текста.

Решение — составной стек с поглифным fallback (`01-fonts.css`):
латиница → Syne, кириллица → **Unbounded** (ближайший display-гротеск с кириллицей);
тех-элементы: латиница → Space Grotesk, кириллица → **JetBrains Mono**.

Замерено в браузере: `Работа` в стеке = 284.7px = ровно Unbounded, против 211.5px системного.

> Пробовал сначала `@font-face` + `unicode-range` + `local()` — не работает:
> `local()` матчит только шрифты, установленные в системе, а Google Fonts
> отдаёт веб-шрифты. Поглифный fallback решает то же самое и надёжнее.

### Производительность
- **Tailwind CDN убран.** Вместо ~420 КБ JS с рантайм-компиляцией — `tailwind.built.css` (191 правило, ровно те 230 утилит, что встречаются в разметке). Крупнейший единичный выигрыш по TBT/LCP.
- Один `requestAnimationFrame` на всю страницу (`core/raf.js`), все canvas-модули — его подписчики.
- Все фоны и инфографики — динамический `import()` по подходу секции. Three.js (~155 КБ) грузится только за 600px до секции VPN.
- `core/canvas.js`: DPR-cap (2 / 1.5 на мобильных), пауза по `IntersectionObserver` и `visibilitychange`, адаптивная деградация числа частиц при просадке кадра, предрендеренный glow-спрайт вместо дорогого `ctx.shadowBlur` на мобильных.

### Доступность
Все проверки контраста — **PASS AA**, включая каждую кнопку в самой тёмной точке её градиента:

| Элемент | Контраст |
|---|---|
| gray-400 на карточке | 6.70 : 1 |
| gold-кнопка (текст `#3b1d00`) | 7.18 : 1 |
| emerald-кнопка (`#022c22`) | 5.97 : 1 |
| pink-кнопка (`#2b0733`) | 5.14 : 1 |
| cyan-кнопка (`#04232c`) | 6.75 : 1 |
| red-кнопка (белый) | 6.47 : 1 |
| violet-кнопка (белый) | 5.17 : 1 |

Плюс: skip-link, `aria-labelledby` на всех 10 секциях (все ссылки резолвятся),
3 `figcaption` с текстовым описанием инфографик, предупреждение о новой
вкладке на всех внешних ссылках, `.scroll-indicator` стал `<button>`,
глобус фокусируемый и вращается стрелками, ноль положительных `tabindex`,
клоны слоёв заголовка помечены `aria-hidden` и исключены из выделения.

### Watchdog
`core/watchdog.js` через 4 c проверяет, виден ли заголовок первого экрана.
Если анимационный конвейер не доехал (упал плагин, оборвалась загрузка CDN),
страница принудительно приводится в финальное статичное состояние: всё видно,
все числа настоящие. Без него отказ выглядел бы как пустые блоки и «доход 0 ₽».

## Ассеты Higgsfield

7 ассетов, 4.9 кредита, суммарно 354 КБ — подробности в `tools/hf-generate.md`.
OG-превью с вордмарком «PRO MAX HUB» отрендерил `nano_banana_pro` с первой
попытки, накладывать типографику отдельно не понадобилось.

Видео-лупы из ТЗ не делались: один клип 5 с стоит 7.5 из 10 кредитов,
четыре — 30. Их роль закрыли статичные ambient-подложки, лежащие
**под** canvas-анимацией секции, плюс уже имеющиеся canvas/WebGL-фоны.

Подключение — только через переменные `--tex-*` в `00-tokens.css`.
Чтобы отключить любой ассет, достаточно закомментировать строку:
везде объявлен процедурный fallback.

### Своя обработка изображений
На машине нет ffmpeg, ImageMagick и Pillow, поэтому в `tools/` лежат
`png.cjs` (декодер + энкодер PNG) и `jpeg.cjs` (baseline JPEG-энкодер:
YCbCr, 4:2:0, FDCT, таблицы Annex K). PNG для фотографического кадра
1200×630 весил 842 КБ, JPEG q86 — 69 КБ. Все семь файлов проверены на
декодирование в Chrome: верные размеры, осмысленная яркость.

## Известные ограничения

1. **Flip реализован частично.** F1 (hero-статистика → липкий тикер-бар) сделан. F2–F5 намеренно не делались: те же узлы уже получают направленные fly-in профили в `fx/reveal.js`, и вторая анимация конфликтовала бы по `transform`. Причина зафиксирована в шапке `fx/flip.js`.
2. **Скриншотов нет** — панель браузера в этой сессии не отображается, страница не композитит кадры, поэтому `IntersectionObserver` и `rAF` не запускаются сами. Обошёл это отладочным методом `raf.tickOnce()` (в `core/raf.js`), который прогоняет кадр вручную. Проверка выполнена на уровне пикселей: после 60 принудительных кадров у каждого холста считаны `ImageData` в нативном разрешении.

   | Холст | Покрытие полосы 1581×300 | maxAlpha |
   |---|---|---|
   | live-терминал `#contracts` | 40.6% (даунскейл) | 255 |
   | `candlesBg` | 2.24% | 74 |
   | `networkBg` | 1.17% | 198 |
   | `neuralBg` | 0.85% | 235 |
   | `goldDustBg` | 0.32% | 52 |
   | `ytSparksBg` | 0.13% | 77 |

   Так нашлась и исправлена реальная недоработка: искры в `#youtube`
   рисовались со средней альфой 4.8/255 — формально работали, фактически
   были невидимы. Подняты до `.12–.30`.

   Чего этим способом проверить нельзя: субъективную красоту движения и
   тайминги. Их надо смотреть глазами — `node devserver.cjs`.
3. **Scroll-jacking не делался** осознанно — вместо него мягкий snap с допуском 2.2% (`core/smooth.js`), отключаемый на тач-устройствах и при reduced-motion.

# Redesign — текущее состояние

Минималистичный редакционный язык: глубокий void, крупная типографика,
воздух, фоновые видео как основной motion. Карточных сеток и залитых
кнопок в контентных секциях нет — проверено, `.card`/`.panel` в разметке 0.

## Паттерны

| Паттерн | Где | Что делает |
|---|---|---|
| `.topbar` | глобально | тонкая полоса, фон проявляется после 40px скролла, активный пункт и счётчик `01…07` по ScrollTrigger |
| `.hero--wide` | Hero | текст слева, 2 строки из маски, сумма в подзаголовке, текстовая CTA |
| `.sec-head` + `.rows` | Contracts, Prop, Neural, VPN | продукты как редакционные строки: индекс, тело, сумма справа |
| `.facts` | Работа из дома, Без стресса | пункты без коробок, только волосяные линии |
| `.numrow` / `.specs` | Без начальников, Neural, VPN | крупные цифры в строку |
| `.cities` / `.slogans` | Живи где хочешь, YouTube | перечни строками |
| `.claim` | итоги секций | крупное типографическое утверждение вместо панели |

## Reveal-паттерны

Только на входе секции, ничего поверх видео:

- `data-rv="up"` — заголовки и лиды, `clip-path` + `y`
- `data-rv="row"` — редакционные строки: маска снизу, затем тело, затем сумма
- `data-rv="lines"` — перечни: все дети по очереди

`data-rv="row"` применим **только** к `.row`: обработчик адресует
`children[0..2]` как индекс/тело/сумму. На блоках с другой структурой
он сдвигал первых трёх детей и блоки наезжали — отсюда отдельный
`lines`.

## Видео-слоты

6 слотов, механика в `sectionVideo()`:

| Секция | Файл | Статус |
|---|---|---|
| hero | `hero-wilderness.mp4` | есть, 3.66 МБ |
| motivation-1 | `amb-room-b.mp4` | есть, 3.43 МБ |
| contracts | `sec-trading.mp4` | ждёт файл |
| prop | `sec-prop.mp4` | ждёт файл |
| neural | `sec-neural.mp4` | ждёт файл |
| vpn | `sec-vpn.mp4` | ждёт файл |

Файла нет → `error` → слой снимается молча, вёрстка не меняется.
Положили файл в `assets/video/` под нужным именем → работает без правок кода.

**Бесшовная петля без ffmpeg.** Два `<video>` одного файла со сдвигом на
половину длительности, кроссфейд по прозрачности. Момент перезапуска
всегда на прозрачном слое. `align()` подтверждает сдвиг после старта и
на каждом переключении: `currentTime` — асинхронный seek, и `play()`
сразу после присвоения стартует со старой позиции, смещение схлопывалось
в 0.07 с вместо 2.52.

**Две шкалы прозрачности разведены физически.** Внешний `.sec-video` —
базовая видимость через класс `.ready`, внутренний `.sec-video__fade` —
затухание при скролле через GSAP. На одном узле inline-стиль GSAP
перебивал класс и слой не появлялся вовсе.

**Прозрачность 0.48** подобрана замером: при 0.20 скрим съедал клип
почти в ноль. Скрим асимметричный (`data-scrim="left"`): слева 0.90 →
справа 0.12, текст лежит на плотном, клип открыт там, где его видно.

## Замеры

18 текстовых стилей над фоном секции — **все PASS WCAG AA**.
Худшие: описание строки и текст факта 7.81:1, подпись суммы 7.81:1.
Над видео в Hero: H1 13.21:1, подзаголовок 11.67:1, строка фактов 5.72:1.

Раскладка на 320 / 375 / 414 / 768 / 1024 / 1440 / 2560 —
**0 наложений, 0 переполнений, горизонтальной прокрутки нет.**

`index.html` — 85.8 КБ (CSS 26 КБ, JS 29 КБ), 37 иконок в SVG-спрайте.
Удалено 94 мёртвых CSS-правила от карточной вёрстки.

## Что не закрыто

1. **Вес видео.** 3.4–3.7 МБ на клип против оговорённых ≤900 КБ.
   Страница без видео 1.1 МБ, все видео вместе — 12 МБ.
   Перекодировать нечем: ffmpeg/ImageMagick/Pillow на машине нет.
   Нужен внешний конвертер до 720p / CRF 30.
2. **`amb-room-a.mp4`** (4.1 МБ) не используется ни одной секцией.
3. **Вертикальных версий 9:16 нет** — на мобильных видео не показывается.
4. **Первые два клипа не по промпту:** просился топографический ландшафт,
   пришла комната с жалюзи. Третий (`hero-wilderness.mp4`) попал точно.
5. **Движение видео своими глазами не проверено:** вкладка в этой среде
   не рисует кадры, `IntersectionObserver`, `rAF` и CSS-переходы там
   заморожены. Проверялось через DOM, `readyState` и офлайн-композит.
